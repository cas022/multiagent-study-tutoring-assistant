Runs twice below - pass 1 with an assumed 10px to get a first estimate, pass 2 re-estimating line counts with pass 1's result for a closer final answer. Two passes converge close enough in practice; a third would move the result by hundredths of a pixel. Budget: each row's rendered height ≈ font_px * (line_count * 1.38 [line-height] + 1.1 [top+bottom padding, since tbl_pad_v = font*0.55]). The budget is 480px of chrome-free height (the same calibration source as quiz-recap.html's identical chrome and margins) LESS whatever the footnote lane takes. That subtraction is new. The lane now sits in normal flow rather than as an absolute overlay (see the .footnote rule above), so its height is genuinely unavailable to the table instead of being space the table could quietly render over. The old budget assumed all 480px regardless of how many footnotes a slide carried, which is precisely the assumption that let a full table and a two-line source note claim the same 20px. Reserve is estimated at 10px/1.4 line-height over an ~1168px lane width, plus the lane's own 12px top margin, and capped at the CSS max-height so this can never subtract more than the lane can actually occupy. This remains an estimate, and it is no longer the last word: verify_render.py measures the rendered result and re-renders at a smaller step if the estimate was wrong. The estimate's job is to land close enough that the measured pass usually agrees on the first try. #} {%- macro solve_font(assumed_font) %} {%- set acc = namespace(total_lines=0.0, n_rows=0) %} {%- for group in groups %} {%- if group.group_label %} {%- set acc.total_lines = acc.total_lines + 1.0 %} {%- set acc.n_rows = acc.n_rows + 1 %} {%- endif %} {%- for row in group.rows %} {%- set row_max = namespace(v=0.0) %} {%- for cell in row.cells %} {%- set cl = cell_lines(cell, col_width_px[loop.index0], assumed_font) | float %} {%- if cl > row_max.v %}{%- set row_max.v = cl %}{%- endif %} {%- endfor %} {%- set acc.total_lines = acc.total_lines + row_max.v %} {%- set acc.n_rows = acc.n_rows + 1 %} {%- endfor %} {%- endfor %} {%- set acc.total_lines = acc.total_lines + 1.0 %} {%- set acc.n_rows = acc.n_rows + 1 %} {%- if show_letter_header %} {%- set acc.total_lines = acc.total_lines + 1.0 %} {%- set acc.n_rows = acc.n_rows + 1 %} {%- endif %} {%- set fn = namespace(chars=0) %} {%- for note in (footnotes | default([])) %} {%- set fn.chars = fn.chars + (note | string | length) + 4 %} {%- endfor %} {#- Lines here means STACKED lines, which is what costs height. Columns are a line-length decision, not a fitting one. #} {%- set fn_lines = ((fn.chars / 224) | round(0, 'ceil')) %} {%- set fn_reserve = 0 if fn.chars == 0 else [142, (12 + fn_lines * 14)] | min %} {%- set budget_px = 480 - fn_reserve %} {{- budget_px / (1.38 * acc.total_lines + 1.1 * acc.n_rows) -}} {%- endmacro %} {%- set font_pass1 = solve_font(10) | float %} {%- set font_pass2 = solve_font(font_pass1) | float %} {%- set tbl_font = font_pass2 %} {%- if tbl_font > 12 %} {%- set tbl_font = 12 %} {%- elif tbl_font < 8 %} {%- set tbl_font = 8 %} {%- endif %} {%- set tbl_font = tbl_font | round(1) %} {%- set tbl_pad_v = (tbl_font * 0.55) | round(1) %} {%- set tbl_pad_h = (tbl_font * 0.85) | round(1) %} {%- set ns = namespace(row_num=0) %}
